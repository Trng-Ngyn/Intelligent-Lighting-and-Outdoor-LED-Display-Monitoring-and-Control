# PCCOM W5-FE — Operations Console

React + Vite + Tailwind CSS + Axios + TanStack Query + Leaflet + Recharts.

Requires Node.js 22 LTS (or newer compatible LTS). From this directory, copy `.env.example` to `.env`, set API configuration, then `npm install`, `npm run dev`. For a release build use `npm run build`. See the root README for integration and acceptance test details.
